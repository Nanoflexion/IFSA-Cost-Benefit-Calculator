## View the Calculator

To see the calculator, go to https://nanoflexion.github.io/IFSA-Cost-Benefit-Calculator/.

## Set Up Instructions

To set up the project, run:
```bash
npm install
```

To see the calculator in your local browser:
```bash
npm run dev
```

To run the tests:
```bash
npm test
```

To create the file for Wix (`dist/nanoflexion-calculator.js`):
```bash
npm run build
```

To create the demo site (which runs on GitHub pages):
```bash
npm run build:pages
```

The demo site updates automatically on every push to `main`.
